# DepthLight iOS

Native iPhone prototype for a realtime virtual light over the live camera preview.

## Features
- SwiftUI dark interface
- Front/rear camera preview
- Draggable virtual light orb
- Light color and intensity controls
- Depth-capability detection on supported cameras
- Photo capture to Photos
- GitHub Actions unsigned IPA build

> The first build is an MVP. The live orb is rendered as a realtime overlay; true per-pixel depth relighting can be added with Metal/Core ML in the next iteration.
